Privacy Policy

Last updated: 2026-11-09

This policy applies to Bitwaddle Studio ("the tool"), a personal tool operated by the owner of the Bitwaddle channel ("the owner") to publish the owner's own videos to the owner's own TikTok account.

What the tool accesses

  • When the owner logs in with TikTok (Login Kit), the tool receives the account's basic profile information (display name) and an access token.
  • With the owner's confirmation, the tool uploads a video file and its caption to the owner's TikTok account through the Content Posting API.

How data is stored

  • The access token and app credentials are stored only on the owner's own computer, in a local file that is not shared or published.
  • The tool does not run a public server, does not collect data from any other person, and has no analytics or advertising.

Sharing

The tool does not sell, share or transfer any data to third parties. Data is sent only to TikTok as part of publishing the owner's own video.

Retention and deletion

The owner can delete the stored token at any time, and can revoke the tool's access in TikTok under Settings and privacy, Security and permissions, Apps and services.
